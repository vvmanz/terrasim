# Your robots

Put robot files here: `configs/robots/<name>.json`, then run `bash scripts/drive.sh --robot <name>`.
They are listed by `bash scripts/drive.sh --list` together with the built-in robots.

Ready examples to copy: [`examples/robots/`](../../examples/robots) (a skid-steer robot, a differential robot with a
caster, a Husky with a payload). Every key: [docs/en/ROBOTS.md](../../docs/en/ROBOTS.md) ·
[docs/ru/ROBOTS.md](../../docs/ru/ROBOTS.md). Step-by-step: [docs/en/EXAMPLES.md](../../docs/en/EXAMPLES.md) ·
[docs/ru/EXAMPLES.md](../../docs/ru/EXAMPLES.md).
