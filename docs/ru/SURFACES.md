# Поверхности: параметры, библиотека, свои поверхности

[English version](../en/SURFACES.md)

Поверхность (покрытие пола или грунт) — это один набор чисел для закона контакта из
[PHYSICS](PHYSICS.md#2-контакт-колеса-с-поверхностью-omnihpp-omnicontact). Закон один для всех поверхностей и всех
роботов, различаются только числа.

Где лежат поверхности:
* `configs/calibrated_params.json` → `robotino.surfaces` — базовая библиотека (18 поверхностей), доступна любому роботу;
* `configs/surfaces_husky.json` — 27 поверхностей для роботов с обычными шинами (сделана для Clearpath Husky, подходит
  любому роботу): `--surface-file configs/surfaces_husky.json`;
* свои JSON-файлы (`--surface-file my.json`), файлы карт (`surfaces:` в карте) и `--set` в командной строке.

Список с параметрами: `bash scripts/robotino.sh --list` (базовая библиотека) или `bash scripts/drive.sh --list`.

## 1. Параметры

### 1.1 Сцепление (закон сдвига Яноши)
| параметр | ед. | смысл | типичные значения |
|---|---|---|---|
| `mu` | – | предел трения tg φ: резина по покрытию или внутреннее трение грунта | мокрое гладкое 0.3–0.4; ковры, резина 0.8–1.4; грунты 0.2–0.7 |
| `phi_deg` | ° | то же как угол трения; используется, только если `mu` не задан (у всех поверхностей библиотеки `mu` задан, поэтому меняйте `mu`) | |
| `c` | Па | сцепление (адгезия), действует на площадь пятна | покрытия 0; песок 1–1.5 кПа; глина 4 кПа |
| `K` | м | модуль сдвиговой деформации: какой сдвиг нужен, чтобы трение «включилось». **Главный параметр проскальзывания** при обычных нагрузках: s ≈ 2K·H/(μ·N·L) | твёрдые 3–7 мм; ворс 5–10 мм; грунты 10–25 мм |
| `patch_len` | м | длина пятна на твёрдом основании (деформация протектора); `patch` колеса её заменяет | 0.01 |
| `slip_norm` | 0/1 | 1 — сдвигается элемент земли (ворс, пена, грунт); 0 — элемент колеса | 1 (установлено по Robotino) |

На твёрдом полу при обычной тяге видно только отношение μ·L/(2K) — «жёсткость» тяга–скольжение. Сам μ виден, только
если колёса подходят к пределу трения (разгон, склоны, тяжёлые роботы).

### 1.2 Потери (то, на что тратится ток)
| параметр | ед. | смысл | типичные значения |
|---|---|---|---|
| `f_roll` | – | сопротивление качению колеса: момент f_roll·N·r через свой мотор | 0–0.09 (ролики Robotino), шины 0.01–0.05 |
| `f_lat` | – | сопротивление качению роликов (омни, меканум), сила на ступицу | стол 0.006; EVA 0.13; ворс, резина 0.3–0.5 |
| `mu_rb` | – | трение подшипников роликов (свойство колеса; `mu_rb` колеса его заменяет) | 0.049 (Robotino) |

### 1.3 Слой Беккера (только мягкие поверхности)
Включается, если `kc` или `kphi` > 0. Давление–осадка p = (kc/b + kphi)·zⁿ.
| параметр | ед. | смысл | типичные значения |
|---|---|---|---|
| `kc`, `kphi` | Н/м^(n+1), Н/м^(n+2) | модули Беккера | грунты — таблицы Вонга; ворс, пена — по нужной осадке (§4) |
| `n` | – | показатель осадки | грунты 0.5–1.1; пена, ворс 1 |
| `b_contact` | м | ширина протектора; `b` колеса её заменяет | 0.03 (Robotino) |
| `layer` | м | толщина мягкого слоя на жёстком основании: осадка не больше её | ворс 6–15 мм, мат 20 мм; грунт — не задаётся |
| `rebound` | 0…1 | упругое восстановление за колесом: теряется только (1 − rebound) работы уплотнения | грунты 0; ворс 0.7–0.75; пена 0.8–0.9 |

### 1.4 Неоднородность
| параметр | смысл |
|---|---|
| `cv_res` | коэффициент вариации f_roll, f_lat, mu_rb |
| `cv_grip` | коэффициент вариации K |
| `cv_soil` | коэффициент вариации kc, kphi (грунты) |
| `corr_len` | длина корреляции, м (покрытия Robotino 1 см, грунты 5 см, библиотека Husky 0.1–0.2 м) |
| `field_seed` | номер реализации поля |

Все `cv_*` = 0 — идеально однородная поверхность.

### 1.5 Численные
`kn`, `cn` — пружина-демпфер контакта (2·10⁵ Н/м, 300 Н·с/м). Это не свойства пола, их не трогайте.

Прочие ключи в файлах: `_kind` / `_group` (группа для `--surfaces real|synthetic|...`), `_doc` (описание), `_src`
(откуда каждое число), `_color` (цвет в Gazebo и на картинках). Ключи, начинающиеся с `_`, физика не читает.

## 3. Библиотека для шин (`configs/surfaces_husky.json`)

| группа | поверхности | откуда |
|---|---|---|
| hard | `asphalt_dry`, `asphalt_wet`, `concrete_wet`, `gravel_road`, `earth_dry`, `earth_wet`, `snow_packed`, `ice_road`, `indoor_floor` | таблицы сцепления шины с дорогой и сопротивления качению (Вонг, «Theory of Ground Vehicles», табл. 1.1, 1.3) |
| soil | `lete_sand`, `sandy_loam_15`, `sandy_loam_32`, `clay_38`, `grenville_loam`, `snow_us`, `snow_sweden`, `mars_soil` | наборы Беккера–Яноши (Вонг, табл. 2.3; MarsSim) |
| intermediate | `asphalt_damp`, `slush`, `loam_moist` | интерполяция между двумя записями с источниками |
| fitted | `paved_fit`, `flooring_fit`, `ice_fit`, `sandy_loam_fit`, `meadow_fit`, `gravel_fit` | подобраны по записям реального Husky A200 (открытые датасеты BorealTC и RoboNav) |

У каждой записи в `_src` указано, откуда каждое число: `[H]` справочник / литература, `[F]` подобрано по записям,
`[E]` оценка в физически правдоподобных пределах, `[S]` синтетика. Разброс (`cv_*`, `corr_len`) каждой поверхности
определён по колебаниям токов моторов бортов реального Husky (`_spread_doc` в файле).

```bash
bash scripts/drive.sh --robot husky --surface-file configs/surfaces_husky.json --surface gravel_fit --traj square:L=4,rc=0.6
bash scripts/drive.sh --robot jackal --surface-file configs/surfaces_husky.json \
     --floor "voronoi:surfaces=asphalt_dry+meadow_fit+gravel_fit,cell=2" --traj circle:R=2.5
```

## 4. Своя поверхность

### 4.1 Файл поверхностей
Напишите JSON-файл. `base` берёт все параметры существующей поверхности, вы меняете только то, что отличается.
Готовый пример — [`examples/my_surfaces.json`](../../examples/my_surfaces.json):

```json
{
 "surfaces": {
  "linoleum_soft": {"base": "table", "mu": 0.8, "f_lat": 0.012, "_doc": "мягкий линолеум"},
  "gravel_like":   {"base": "sand_lete", "cv_soil": 0.4, "cv_res": 0.2, "corr_len": 0.10}
 },
 "speeds": {"linoleum_soft": [0.1, 0.2, 0.3]}
}
```

Ключ `"surfaces"` верхнего уровня необязателен (подойдёт и просто словарь `{имя: {...}}`). `speeds` нужен только
«звезде» Robotino. Дальше:

```bash
bash scripts/drive.sh --surface-file my.json --surface linoleum_soft --robot burger
bash scripts/drive.sh --surface-file my.json --floor "half:surfaces=gray+linoleum_soft" --robot robotino --traj line:L=3
bash scripts/robotino.sh --engine emulate --surface-file my.json --surfaces linoleum_soft,gravel_like
```

Поверхности из файла попадают в группу `user` (`--surfaces user` в `robotino.sh`).

### 4.2 Без файла
* поменять одно значение на один прогон: `--set carpet.K=0.008 --set carpet.mu=0.7`;
* перебрать значения («звезда» Robotino): `bash scripts/robotino.sh --engine emulate --surfaces carpet --sweep carpet:mu=0.6,0.8,1.0`
  создаёт `carpet_mu0.6`, `carpet_mu0.8`, `carpet_mu1.0`;
* поверхность только для одной карты: `surfaces:` в файле карты ([MAPS](MAPS.md#2-формат-файла)).

### 4.3 Как сделать физически обоснованную поверхность
1. **Начать с ближайшей измеренной** (`"base": "table"`, `"gray"`, `"sand_lete"`...). Всё, что вы не меняете, остаётся
   измеренным.
2. **Менять по одной физической оси:**
   * трение (вода, пыль, материал протектора) → `mu`;
   * податливость ворса или грунта на сдвиг → `K`;
   * потери в роликах → `f_lat`; гистерезис шины или ролика → `f_roll`;
   * мягкий слой → `kphi`, `n`, `layer`, `rebound`;
   * неоднородность → `cv_*`, `corr_len`.
3. **Мягкий слой — по нужной осадке.** При n = 1, нагрузке на колесо N и ширине протектора b жёсткое колесо радиуса r
   садится на z при kphi ≈ 3N / (2·b·√(2r)·z^1.5). Для Robotino (N ≈ 36 Н, b = 0.03 м, r = 0.04 м): kphi ≈ 6400 / z^1.5
   (z = 2.5 мм → 5.1·10⁷, z = 6 мм → 1.4·10⁷ Н/м³). Проверка: давление p = kphi·z должно быть реалистичным.
4. **Для грунтов брать полный опубликованный набор** (kc, kphi, n, c, φ, K) — Вонг, «Theory of Ground Vehicles»;
   Беккер; базы Chrono SCM. Не смешивать значения разных грунтов.
5. **Проверить сводку** пробного прогона: осадка меньше `layer` и заметно меньше 0.3·r, сопротивление уплотнению / N
   меньше ~0.3, отношение скоростей больше 0.1, если поверхность должна быть проезжаемой.
6. **Перебрать неуверенный параметр** (`--sweep` или пакет `--set`), чтобы увидеть, на что он влияет.

## 5. Какой параметр что двигает

| хочу | крутить |
|---|---|
| больше проскальзывание при обычной езде | `K` ↑ |
| робот буксует при разгоне и на подъёме | `mu` ↓ |
| больше ток на прямой при том же скольжении | `f_roll` ↑ |
| омни-робот сильнее проскальзывает и рыскает | `f_lat` ↑ |
| колея глубже, ток на мягком больше | `kphi` ↓ или `layer` ↑ |
| ковёр «дешевле» по энергии | `rebound` ↑ |
| больше разброс внутри прогона | `cv_res`, `cv_grip` ↑ |
