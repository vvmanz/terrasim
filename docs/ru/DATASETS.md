# Синтетические датасеты Robotino (`scripts/robotino.sh`)

[English version](../en/DATASETS.md)

Модель Robotino откалибрована по лабораторным записям реального Festo Robotino, который ездит «звездой».
`robotino.sh` повторяет тот же эксперимент на любой поверхности и пишет результат **в том же формате, что и
лабораторные записи** (41 столбец `dataset_belyaev.csv` и 90 столбцов расширенной `belyaev_kushnarev.csv`), поэтому
реальные и симулированные данные обрабатывает один и тот же код. Сами записи в репозиторий не входят.

## 1. Эксперимент

* Робот едет без регулятора пути (только регулятор скорости прошивки Robotino) по **лучам**: прямая в направлении
  `movedir` = 0°, 5°, …, 355° (72 луча, `--dirs`) со скоростью `speedamp`, курс не меняется.
* Один луч длится `t_run` = 18 / 10 / 6 с при 0.1 / 0.2 / 0.3 м/с (`--t-run`), пауза между лучами 1.5 с.
* Запись с частотой камеры (30 Гц), время `t` в мс, обнуляется в начале каждого луча.
* По желанию: карта рельефа (`--map`) и возврат в центр после каждого луча (`--return`).
* Скорости по поверхностям — из `configs/calibrated_params.json` → `robotino.experiment.speeds` (или `--speeds`).

```bash
bash scripts/robotino.sh --engine emulate --surfaces real                 # gray, green, table, red
bash scripts/robotino.sh --engine harmonic --surfaces all --jobs 4        # все поверхности библиотеки в Gazebo
bash scripts/robotino.sh --engine emulate --surfaces gray --speeds 0.1,0.2,0.3 --noise clean --out datasets/gray_clean
```

## 2. Папка результатов (`datasets/<дата>_<движок>/`)

| файл | что внутри |
|---|---|
| `dataset_clean.csv`, `dataset_noisy.csv` | все прогоны вместе |
| `csv/<поверхность>_<скорость>_clean.csv`, `_noisy.csv` | одна поверхность и скорость, пишется сразу после прогона |
| `dataset_ext_clean.csv`, `dataset_ext_noisy.csv`, `csv/*_ext_*.csv` | расширенный формат на 90 столбцов (§4); `--no-ext` отключает |
| `csv/<поверхность>_<скорость>_full.csv.gz` | полный лог прогона, 50 Гц ([OUTPUTS](OUTPUTS.md#3-fullcsvgz-полный-лог-прогона)); `--full-rate`, `--no-full` |
| `summary.csv`, `summary.md` | по поверхностям и скоростям: отношение скоростей \|v\|/v_cmd, скорость рыскания, скольжение и ток ведущих колёс, Ke, осадка, сопротивление уплотнению, темп счёта |
| `surfaces_constant.csv` | параметры всех использованных поверхностей и какие из них меняются вдоль пути |
| `figures/` | скольжение против тока мотора (clean и noisy) с прямыми, Ke по направлению; таблицы окон 0.5 с |
| `params_used.json` | параметры робота и поверхностей этого прогона |
| `runs/<поверхность>_<скорость>/` | `experiment.ini`, мир, сырые логи, `console.log` |

**clean** — истинные сигналы симуляции, снятые как лабораторным логгером. **noisy** — тот же прогон через модель
измерений стенда (`tools/robotino_sensor.py`): логгер 32 Гц читает камеру 29.4 Гц (≈8 % кадров повторяют предыдущий
кадр камеры, скорость в них 0), шум положения и курса камеры, квантование скорости энкодера с шагом 2.8274 рад/с на
моторе, шум тока и квантование 1/39 А. Эти параметры определены по лабораторным записям.

## 3. Столбцы (41 + столбцы поверхности)

Колёса i = 1, 2, 3 на θ = 60°, 180°, 300°; радиус колеса r = 0.04 м, расстояние до центра R = 0.125 м, редуктор 16.

| столбец | ед. | смысл |
|---|---|---|
| `t` | мс | время от начала луча |
| `surf` | | имя поверхности |
| `movedir`, `speedamp` | °, м/с | направление и заданная скорость луча |
| `xsetspeed`, `ysetspeed` | м/с | заданная скорость корпуса |
| `m{i}setvel`, `m{i}vel` | рад/с | заданная скорость мотора и показание энкодера (вал мотора) |
| `m{i}cur` | А | ток мотора (модуль) |
| `m{i}vol`, `m{i}pow` | В, Вт | напряжение U = sign(ω)·I·R + Ce·ω и мощность \|U·I\|, R = 5.3351 Ом, Ce = 0.0501 В·с |
| `xpos`, `ypos`, `ang` | м, м, ° | поза робота по камере |
| `vx`, `vy`, `omega` | м/с, рад/с | скорость корпуса по камере (в осях корпуса) |
| `rpower`, `Ke` | Вт, – | суммарная мощность Σ\|U·I\|; энергетический коэффициент Ke = Σ\|U·I\| / (0.17·Σ\|U\|) |
| `w{i}vel` | рад/с | скорость колеса по энкодеру (`m{i}vel` / 16) |
| `w{i}effvel` | рад/с | скорость колеса, которая нужна для движения по камере без проскальзывания: (1/r)(−sin θᵢ·vx + cos θᵢ·vy + R·ω) |
| `w{i}slip` | – | относительное проскальзывание 1 − `w{i}effvel` / `w{i}vel` (0, если скорость мотора в пределах одного шага энкодера от 0) |
| `w{i}linslip` | – | \|sin(φ − θᵢ)\|·`w{i}slip`, φ — направление скорости по одометрии колёс |
| `w{i}_x, w{i}_y` | м | точка контакта колеса (только симуляция) |
| `w{i}_mu, _K, _f_roll, _f_lat, _mu_rb, _kc, _kphi` | | параметры поверхности под колесом в этот момент с учётом неоднородности (только симуляция) |

`--strict-format` убирает столбцы поверхности `w{i}_...` и пишет ровно 41 столбец лабораторных файлов.

## 4. Расширенный формат (90 столбцов)

Расширенная таблица добавляет 49 столбцов, которые лабораторная программа вычисляет из базовых. Каждая формула найдена
по всей лабораторной таблице и воспроизводится точно (`tools/robotino_ext.py`, коэффициенты фильтра — в
`configs/robotino_ext_filter.json`):

| столбцы | смысл |
|---|---|
| `exp_idx`, `run_idx` | номер луча во всей таблице / внутри одной поверхности |
| `setvel` | всегда 0 (оставлен ради формата) |
| `m{i}pos` | счётчик энкодера с начала луча, 1970 импульсов на оборот мотора |
| `xcur, ycur, rotcur` | M⁻¹·(токи со знаком), строки M = (−sin θᵢ, cos θᵢ, 1) |
| `w{i}ddvel` | `w{i}vel − w{i}effvel`, скорость проскальзывания колеса, рад/с |
| `ddvx, ddvy, ddomega`, `ddspeedvec` | скорости проскальзывания, пересчитанные на корпус; \|v_одометрии\| − \|v_камеры\| |
| `*_kalman`, `m{i}esttor` | линейный фильтр Калмана мотора с состоянием [скорость мотора, момент нагрузки]; `m{i}esttor` — оценка момента нагрузки на валу мотора, Н·м; столбцы `_kalman` повторяют базовые формулы с фильтрованными значениями |

`python3 tools/robotino_ext.py --check <лабораторный файл>` восстанавливает таблицу по её 41 базовому столбцу и
сравнивает все 90 (если у вас есть такая запись).

## 5. Рисунки и дальнейшая обработка

```bash
python3 tools/robotino_figures.py datasets/<папка>/dataset_clean.csv --out /tmp/fig   # скольжение против тока, окна 0.5 с
python3 tools/robotino_merge.py datasets/<a> datasets/<b> --out datasets/<объединённая>    # объединить папки (побеждает последняя)
bash scripts/robotino_missing.sh datasets/<папка> --engine emulate                      # досчитать недостающие пары (поверхность, скорость)
python3 tools/robotino_sensor.py --dataset my_recording.csv --sim datasets/<папка>/dataset_clean.csv
#   покадровая статистика своей записи рядом с симуляцией, пропущенной через модель измерений
```

Окна 0.5 с (первая секунда каждого луча пропускается): w_act — скорость колеса по энкодеру, w_eff — скорость по
движению корпуса, скольжение s = 1 − w_eff/w_act, взвешенное скольжение s·\|sin(α − θᵢ)\|; на рисунках они построены
против тока мотора каждого колеса с прямой для каждой поверхности.

## 6. Как пользоваться датасетами
* **Классификация и оценка поверхности:** ток, скольжение и Ke по окнам; столбцы `w{i}_mu, _K, ...` — истинные
  параметры поверхности под каждым колесом.
* **Неоднородность:** разброс внутри прогона даёт поле поверхности (`cv_res`, `cv_grip`, `corr_len`); для идеального
  пола обнулите его: `--set <поверхность>.cv_res=0 --set <поверхность>.cv_grip=0`.
* **Воспроизводимость:** одна и та же команда даёт одни и те же данные (фиксированы `field_seed` и `--seed`); другой
  `--seed` — другая реализация шума.
