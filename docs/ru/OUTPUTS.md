# Результаты: папки, столбцы логов, метрики

[English version](../en/OUTPUTS.md)

Здесь описан `scripts/drive.sh`. Датасеты Robotino из `scripts/robotino.sh` описаны в [DATASETS](DATASETS.md); их
полные логи прогонов имеют те же столбцы, что в §3.

## 1. Папка результатов

`runs_drive/<дата>_<движок>/` (или `--out`):

| файл | что внутри |
|---|---|
| `<прогон>/figure.png` | карта (покрытия цветом, изолинии высоты) с заданной, истинной, одометрической и «одометрия + IMU» траекториями; ошибки слежения, токи, проскальзывания по времени (фон — покрытие под роботом); дрейф оценок; IMU |
| `<прогон>/log.csv` | всё по времени с частотой `--log-rate` (50 Гц), §2 |
| `<прогон>/full.csv.gz` | полный лог прогона с частотой `--full-rate` (50 Гц), §3 |
| `<прогон>/metrics.json` | метрики прогона (§4) и по покрытиям |
| `<прогон>/path.csv`, `path_world.csv` | заданный путь в стартовой системе / в системе карты |
| `<прогон>/experiment.ini`, `world.sdf`, `console.log` | что запускалось: INI плагина, мир Gazebo (Harmonic), вывод движка |
| `summary.csv`, `summary.md`, `summary.png` | по строке на прогон, сравнительные столбики |
| `per_surface.csv` | по прогонам и покрытиям: доля времени, ток, продольное и боковое скольжение, осадка |
| `maps/<карта>/` | `map.dtm` (высоты + тип покрытия в узлах) и меши рельефа для Gazebo |

Имя прогона говорит, что запускалось: `<робот>_<карта>_<траектория>_<привод>[-<курс>]_<управление>[_<локализация>]`.

## 2. `log.csv`

Общие столбцы:
* `t` (с), `phase` (0 стоянка до, 1 движение, 2 после конца);
* опора: `ref_x, ref_y, ref_yaw, ref_v, ref_w`;
* истина: `x, y, z, roll, pitch, yaw` (поза звена корпуса), `vx, vy` (в осях корпуса), `wz`;
* оценки: `odo_x, odo_y, odo_yaw` (одометрия по энкодерам), `fus_x, fus_y, fus_yaw` (одометрия + курс по гироскопу);
* IMU: `imu_gx, imu_gy, imu_gz` (рад/с), `imu_ax, imu_ay, imu_az` (м/с²);
* команда регулятора в осях корпуса: `cmd_vx, cmd_vy, cmd_wz`;
* ошибки относительно опорной точки: `e_along, e_cross, e_yaw`;
* `surf` — покрытие под центром робота;
* в конце строки: `tilt_rel` (угол между осью z корпуса и нормалью к земле, °), `body_N` (суммарная опора контакта
  корпуса с землёй, Н), `body_pts` (сколько точек корпуса касаются земли).

По колесу i (в порядке описания робота, 1…n) — `w{i}_...`:

| столбец | что |
|---|---|
| `wset`, `wenc` | заданная скорость колеса и показание энкодера, рад/с |
| `cur`, `vol`, `pow` | ток (А), напряжение (В), электрическая мощность (Вт) мотора этого колеса; у колёс одного мотора — один мотор |
| `tau` | момент мотора на колесо, Н·м |
| `N`, `Fx`, `Fy` | опора; тяга вдоль оси ролика / качения; сила в свободном направлении (ролики) или боковая (шина), Н |
| `slip`, `slip_lat` | продольное и боковое проскальзывание в пятне |
| `sink` | осадка (колея), м |
| `surf` | номер покрытия под колесом (порядок — как в `maps/*/map.dtm`) |

## 3. `full.csv.gz` (полный лог прогона)

Пишется для каждого робота и каждого прогона ядром (`sensors.hpp`, `FullLog`), поэтому столбцы в Gazebo и в эмуляторе
одинаковые. В «звезде» Robotino это `csv/<поверхность>_<скорость>_full.csv.gz`.

Заголовок: `t`, описание прогона (песочница: `robot, control, localization, map`; звезда: `label, speedamp`), `phase`,
`run` и `dir` (номер и направление луча звезды; в песочнице −1 / пусто).

| группа | столбцы | что это |
|---|---|---|
| истина | `x_true, y_true, z_true, roll_true, pitch_true, yaw_true` | поза корпуса из движка |
| | `qw_true, qx_true, qy_true, qz_true` | та же ориентация кватернионом |
| | `vx_true, vy_true, vz_true` | скорость в мире, м/с |
| | `vx_body, vy_body, vz_body` | она же в осях корпуса |
| | `wx_true, wy_true, wz_true` | угловая скорость в осях корпуса, рад/с |
| IMU | `imu_ax, imu_ay, imu_az`, `imu_gx, imu_gy, imu_gz` | измеренные удельная сила (стоя `az ≈ +9.81`) и угловая скорость, с шумом, смещением и блужданием |
| | `imu_*_true` | те же величины без шума и смещения (среднее за такт IMU) |
| одометрия | `odo_ideal_x/y/yaw` | по точным скоростям шарниров (без квантования): от истины отличается только проскальзыванием и рельефом |
| | `odo_enc_x/y/yaw` | по квантованным счётчикам энкодеров |
| | `odo_imu_x/y/yaw` | энкодеры + курс по гироскопу (смещение нуля оценено на стоянке) |
| | | все три в начале движения (в звезде — каждого луча) приравниваются к истинной позе |
| управление | `ref_x, ref_y, ref_yaw` | опорная точка (в звезде пусто) |
| | `cmd_vx, cmd_vy, cmd_wz` | команда в осях корпуса |
| энергия | `power_W`, `energy_J` | электрическая мощность всех моторов и её интеграл |
| | `surf` | имя покрытия под центром робота |

По колесу `w<метка>_...` (метки: `1, 2, 3` у Robotino, `FL, FR, RL, RR`, `L, R, C`, ...):

| столбец | что |
|---|---|
| `angle` | угол поворота колеса с начала прогона, рад |
| `omega`, `omega_set`, `omega_enc` | скорость колеса: истинная, заданная, по энкодеру, рад/с |
| `omega_eff` | скорость колеса, которая нужна при истинном движении корпуса без проскальзывания, J_i·(vx, vy, ωz) |
| `cur`, `volt`, `power` | ток, напряжение, мощность мотора этого колеса |
| `tau_motor` | момент мотора на колесо, Н·м |
| `tau_contact` | момент пятна контакта вокруг оси колеса, Н·м |
| `N`, `F_trac`, `F_free` | опора, тяга, сила в свободном или боковом направлении, Н |
| `Fx, Fy, Fz` | сила пятна в мире, Н |
| `slip`, `slip_lat` | продольное и боковое проскальзывание в пятне (как в модели контакта) |
| `slip_kin` | кинематическое проскальзывание, как в записях Robotino: 1 − `omega_eff`/`omega` |
| `sink` | осадка, м |
| `cx, cy` | точка контакта, м |
| `mu, K, f_roll, f_lat, mu_rb, kc, kphi` | параметры поверхности в точке контакта с учётом поля неоднородности |
| `surf` | имя покрытия под колесом |

У опор нет мотора: `cur, volt, power, tau_motor` равны 0, `F_free` — сопротивление качению, `omega` — скорость
вращения шарика или колеса (v/r при качении), `slip` — скорость проскальзывания обода, м/с (≈ 0 при качении).

## 4. Метрики (`summary.csv`, `metrics.json`)

| метрика | смысл |
|---|---|
| `status` | §5 |
| `wall_s`, `sim_s`, `rtf` | время счёта, время симуляции, достигнутый темп относительно реального времени |
| `path_len_m`, `driven_m`, `T_move_s` | длина заданного пути, реально пройденный путь, длительность движения |
| `xtrack_rms_m`, `xtrack_max_m` | геометрическое отклонение от пути (до ближайшей точки) |
| `track_err_rms_m`, `track_err_max_m` | ошибка относительно движущейся опорной точки |
| `final_err_m`, `yaw_err_rms_deg` | финальная поза относительно конца пути; ошибка курса |
| `odom_drift_m`, `odom_yaw_drift_deg` | дрейф одометрии по энкодерам к концу |
| `fused_drift_m`, `fused_yaw_drift_deg` | дрейф одометрии + IMU |
| `energy_J`, `energy_J_per_m`, `I_mean_A`, `I_max_A` | электрическая энергия, на метр, средний и наибольший ток |
| `slip_mean`, `slip_lat_mean`, `sink_max_mm`, `sink_caster_max_mm` | средние проскальзывания ведущих колёс, наибольшая осадка |
| `tilt_max_deg`, `tilt_rel_max_deg` | наибольший наклон корпуса; наибольший наклон относительно нормали к земле |
| `progress`, `progress_max`, `driven_ratio` | положение вдоль пути в конце (доля длины; сползание назад уменьшает), самая дальняя точка, пройдено / задано |
| `climb_m`, `descent_m`, `terrain_slope_max_deg`, `terrain_slope_end_deg` | рельеф под путём: набор и потеря высоты, самый крутой и конечный уклон под роботом |
| `surface_changes` | сколько раз сменилось покрытие под роботом |
| `tipped_t`, `left_map_t` | время опрокидывания / выезда за карту |

## 5. Статус прогона
* `done` — дошёл до конца;
* `tipped` — корпус наклонился к земле больше чем на `--tip-deg` (50°). С `--on-tip stop` (по умолчанию) прогон
  заканчивается через 0.2 с, метрики считаются до этого момента; с `--on-tip continue` прогон идёт до конца и метрики
  считаются по всему прогону (`tipped_t` — когда это случилось);
* `left_map` — робот уехал или сполз за карту (рельефа там нет, прогон обрезается);
* `diverged`, `stalled`, `FAILED` — сбой симуляции (численная расходимость, лог не растёт `--stall` с, ошибка движка;
  см. `console.log`).
